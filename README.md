# Student Marks Analysis Using Python

## About the Project
This is my first Python project. It analyzes students' marks and displays a simple report using Python.

## Features
- Enter student names and marks
- Calculate total marks
- Calculate average marks
- Find the highest marks
- Assign grades based on marks
- Visualize marks using a bar chart

## Technologies Used
- Python
- Google Colab
- Matplotlib

## What I Learned
- Python dictionaries
- Loops and conditional statements
- Basic calculations
- Data visualization using Matplotlib

## How to Run
1. Open the `Student_Marks_Analysis.ipynb` notebook.
2. Open it in Google Colab.
3. Run the code cells.
4. Enter student names and marks to view the report and chart.
